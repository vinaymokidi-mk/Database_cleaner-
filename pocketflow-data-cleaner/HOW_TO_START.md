# 🚀 How to Start

## Three Easy Ways:

### 1️⃣ **Double-Click** (Easiest)
1. Find `START_APP.bat` in this folder
2. Double-click it
3. Browser opens automatically!

### 2️⃣ **Command Line**
```bash
python app.py
```

### 3️⃣ **PowerShell**
```powershell
python app.py
```

---

## 📱 Then Open Your Browser

Go to: **http://127.0.0.1:7860**

---

## 🎯 What You'll See

Two tabs:
1. **Clean Data** - Upload and clean files
2. **💬 Ask Questions** - Chat with your data

---

## ✅ Quick Test

1. Upload any Excel/CSV file
2. Click "🧹 Clean Data"
3. See results instantly!
4. Download cleaned file

---

## 🛑 To Stop

Press: `Ctrl + C` in the terminal

---

**That's it! Simple and fast!** 🎉
